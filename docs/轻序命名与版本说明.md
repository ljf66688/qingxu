# 轻序 · 饮食与热量记录

用户确认的命名方向：不限定粤菜、表达轻松与平衡、采用短中文主名与功能副标题。
最终选择主推荐「轻序」，副标题「饮食与热量记录」。

## 0.1.1

- 应用名称、首页、关于和许可页面使用新名称；首页展示副标题。
- Android版本名为`0.1.1-offline`，版本号2。
- 保留原应用包名、签名和本地存储标识，以支持旧版覆盖升级。
- 食物库、历史记录、计算口径和离线机制沿用已有实现。
- 同步提供新名称的APK、源码包与22张界面预览。

## 公开名称初筛

本轮未确认精确同名的健康、饮食、热量或体重记录App。
已查到其他领域的近似名称[轻序协同](https://apps.apple.com/cn/app/%E8%BD%BB%E5%BA%8F%E5%8D%8F%E5%90%8C/id6779874515)
和[轻序智记](https://www.qingxuzhiji.com/)。这只是公开应用名称初筛，不能据此认定全平台无重名。

当前版本的实际打包与核验结果见`outputs/轻序-0.1.1-验证记录.md`。
