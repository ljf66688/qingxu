# 中式菜肴热量官方资料核验

核验日期：2026-10-15。本文是有限示例和来源核验记录，不是已经获准再分发的软件食物库。

## 结论

香港食物安全中心提供可直接查证的熟制粥、粉、面、饭营养资料，适合核对数值口径。其《本地粥粉麪飯的營養素含量》报告于2006年3月发表，涉及110款食品，其中包括3种烧味酱汁。该来源侧重香港餐饮，不能代替覆盖川、鲁、湘、苏等菜系的全国成品菜数据库。[官方原报告](https://www.cfs.gov.hk/tc_chi/programme/programme_rafs/programme_rafs_n_01_01_nvic.html)

以下热量均直接核对附件IV“每100克”的“热量（千卡）”栏，不是千焦，也没有用每份热量反推。原报告说明数据为样本均值、保留两位有效数字；因此软件应显示“参考估算”，不应暗示精确到每一家店。

## 抽样、熟重及份量

- 报告研究方法说明：本轮食品于2004年3月至2005年7月购买及分析，每种随机购买10个样本，购入时均可即时食用。实验室仅取可食部分均化分析。因此这些是餐饮成品参考值，不是干米、干面或生肉值。
- 报告同时纳入此前早餐、点心研究中的15款食品，因此不能将全部110款都描述成同一时期新采样。
- 附件V另给“单位重量”和“每单位热量”。例如白粥为450克、140千卡，皮蛋瘦肉粥为470克、260千卡，干炒牛肉河粉为650克、970千卡，扬州炒饭为620克、1200千卡。它们是该研究份量参考，不是用户一碗/一盘的固定定义。
- 每100克与每份数据均已舍入，不应据此相互校正。用户实际称重时，应以每100克栏乘以实际克数计算。

以上方法及份量的出处均为[报告研究方法及附件V](https://www.cfs.gov.hk/tc_chi/programme/programme_rafs/programme_rafs_n_01_01_nvic.html)。

## 另一官方资料入口

[香港食物安全中心《Nutrient Values of Chinese Dim Sum》](https://www.cfs.gov.hk/english/programme/programme_rafs/programme_rafs_n_01_03_ra_dim_sum.html)提供71款点心及3款酱汁的数据；附件V为每100克，附件VI为每件/份。报告说明各类取10个样本，使用样本均值。附件是图片表格，本轮未逐格转录数值。此报告首页也有同类书面许可要求，故不作为已经许可的App内置库。

尚未从本轮官方来源核验出宫保鸡丁、鱼香肉丝、麻婆豆腐等单道家常菜的通用热量，不能用配饭套餐或商业科普估值冒充已核实单菜数据。大陆成品菜应另用来源及许可明确的配方数据集补充。
