# 轻序 · 饮食与热量记录

基础源码来自 OpenNutriTracker v2.4.0（GPLv3），在独立 `offline` 安卓变体与
`lib/offline_main.dart` 入口上开发。保留原版 `lib/main.dart`、上游界面和远程
功能源码，离线入口不会初始化 Supabase、Sentry、健康同步或联网图片。

## 第一版功能

- 早餐、午餐、晚餐：离线搜索名称/常见别名/部分繁体名称，显示每100克热量，
  输入克数后预览并连续添加到同一餐。支持修改、删除和估算标记。
- 收藏与最近食物：收藏食物定义，最近记录可回填克数；收藏页可选择餐次。
- 自建食物及个人热量参考值：支持0千卡食物，调整后可恢复原始参考值。
  已记录食物是独立快照，库内修改不会追溯改变历史。
- 身体资料：性别公式参考、手填周岁年龄、身高、体重；采用成人
  Mifflin–St Jeor静息能量公式。当前公式资料范围为19—78岁。
- 每日手填运动总消耗：保存替换当天总数，可清空，不从“摄入”中抵扣。
- 日/周/月统计：周一至周日、自然月。总量包括全部已记录摄入；日均的
  分子、分母都只取标记完整的日期。估算记录也允许标记完整。
- 核心功能本地运行，使用Hive AES加密及上游Keystore密钥保护。存储失败不
  显示假保存成功；损坏数据不静默清空。离线变体移除联网和无关权限。

本仓库分享项目介绍、预览与源码；尚未上架应用商店。安装包使用独立包名，和官方应用分开。

## 食物库的具体范围

当前92项：42项USDA SR Legacy基础食物、50项本项目编写的粤式/家常示例配方。
基础食物保留原始英文描述与FDC编号；示例配方逐项列出可食成分重量、用油、
整份参考重量及近似烹调数据，均标记为参考估算。没有把研究中的整份菜肴
热量当作每100克熟菜热量。实际配料、部位、含水量、用油不同会影响数值。

原先研究的500道粤菜工作簿现已成功读取，但只有配方总能量和份数，没有
成品可食熟重，因此没有直接批量转成每100克条目。

来源与生成过程见 `assets/offline/README.md`、`usda_provenance.json` 及
`tools/offline/build_catalog.py`。核心流程不需要API密钥、账号或服务器。

## 构建

依照 `.fvmrc` 使用Flutter 3.44.6，Java 17、Android SDK 36、Build Tools 36.0.0，
NDK版本由Flutter固定。首次依赖下载需要联网。

```powershell
flutter pub get
flutter gen-l10n
dart run build_runner build
flutter analyze
flutter test test/offline test/unit_test/meal_nutriments_entity_test.dart
flutter build apk --release --flavor offline -t lib/offline_main.dart --build-name 0.1.1 --build-number 2
```

正式release打包需要本地签名配置 `android/key.properties`，该文件和私钥不提交Git。
离线入口本身不读取 `.env`；保留原版完整工程时，代码生成可从 `.env.example`
复制占位 `.env`，离线功能无需填写上游服务器密钥。

Windows下若中文路径导致Dart AOT/LSP错误，使用英文构建目录：

```powershell
powershell -ExecutionPolicy Bypass -File tools/offline/build.ps1 `
  -FlutterSdk C:\path\to\flutter `
  -JavaHome C:\path\to\jdk17 `
  -AndroidSdk C:\path\to\android-sdk `
  -BuildDirectory C:\path\to\qingxu-build
```

脚本复制源码到外部构建目录，不删除源码，保留所有中间日志；必要时仅为
本次Java进程配置Windows现用代理，完成后将APK复制回 `outputs/`。

测试与打包应串行执行。发布打包不要加`--no-pub`：Flutter需要重新生成排除
开发依赖的原生插件注册文件，否则可能注册发布版未编入的`integration_test`插件。

## 复用与数据边界

离线层按data/domain/presentation组织，复用上游 `MealEntity`、
`MealNutrimentsEntity`、`IntakeEntity.totalKcal`、ID生成和受保护的AES密钥流程。
离线日记写入独立加密状态盒，库、收藏、完整日、运动和身体资料整体保存，
不会写入或迁移官方版本的用户数据库。

首次使用数据为空，预览截图的数据仅来自隔离的测试内存库，不会种入安装包。
卸载或清除应用数据会删除本地记录。

UI截图可通过以下独立测试生成（Windows会读取本机字体，仅用于预览）：

```powershell
flutter test test/offline/preview_test.dart --dart-define=CAPTURE_OFFLINE_PREVIEW=true
```

公开的22张页面与操作弹窗截图见 [全部界面预览](screenshots/qingxu/README.md)。本地重新生成的截图位于 `outputs/preview/`。

当前版本验证与限制见 [验证记录](validation.md)。
